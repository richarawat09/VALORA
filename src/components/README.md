# FRONTEND TIER (UI Component Library)

This directory contains the presentation components for the VALORA healthcare platform.

- **`ui/`**: Core reusable UI primitives (Modal, StatCard, Badge).
- **`forms/`**: Dynamic input dialogs (MedicalRecordUploadModal with permission handling, AppointmentBookingModal, ConsultationNoteModal, PrescriptionModal).
- **`doctor/`**: Doctor-specific clinical widgets (PatientMedicalProfileModal displaying prior consultations and reports).
- **`charts/`**: Health vitals, appointment analytics, and revenue trends rendered using Chart.js.
- **`common/`**: Application navigation shells (Navbar, Sidebar, Footer).
